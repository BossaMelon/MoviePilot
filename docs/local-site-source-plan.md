# 移除平台资格认证并替换站点二进制

## 目标

完全移除指定 PT 平台资格认证的页面、API、启动和定时检查。站点索引逻辑改为 Python，公开规则改为 JSON；构建、安装和更新不得重新安装站点 .so/.pyd/.bin。管理员登录、API/MFA、资源站点实际 Cookie/Token 和插件独立密钥授权保留。以 v3.1.9 为基线，在 volc x86 测试实例验收。先前 bc088b80 保留为恢复点。

## 分工与接口

1. 核心实现：app/application/site/sites.py + sites.json，复用 SiteQueryPort，由启动组合根注入，不越层导入 DB；同步/异步索引、规则合并、域名别名、限流有行为测试。
2. 完整移除平台流程：移除 /site/auth API、启动认证、user_auth 调度和新增站点资格检查；旧插件兼容等级保留为普通能力声明，不实现远程认证，不返回伪造认证成功。清理废弃设置、类型合同与文档。
3. 安装更新：独立任务负责 Docker/CLI/local_setup/资源更新适配与对应测试，确保源码/JSON文件随应用交付，旧站点二进制不会覆盖源码。替换先前补丁脚本和Dockerfile。
4. 前端：独立任务查找并移除平台认证页面入口及调用，保留资源站点登录配置，提供可复现构建的源码和构建产物路径。
5. 代理与验收：复用 volc 已有 127.0.0.1:7890 代理；测试实例独立接入，不改主机已有代理配置。验证 TMDB 实际请求、源文件加载、无站点二进制、无认证API/定时任务、管理员授权边界和站点索引。
